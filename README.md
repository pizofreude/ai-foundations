## What's This?

This is a **cinematic single-page site** paired with an **interactive teaching workbench** built for the KrackedDevs *"AI Foundations 101: Vibe Coding"* workshop. It's the go-to playground for learning how to craft killer prompts and build real apps with AI → no code required.

💡 Think of it as your launchpad into the world of prompt engineering and AI-powered development.

---

## Tech Stack

Built with the classics:

- ⚛️ **React** → UI components
- ⚡ **Vite** → blazing fast dev build
- 🎨 **Tailwind CSS** → utility-first styling
- 🔷 **TypeScript** → type-safe goodness

---

## Getting Started

```bash
# install dependencies
bun install

# spin up the dev server
bun dev

# build for production
bun run build
```

## Why "Vibe Coding"?

Because coding with AI isn't about memorizing syntax → it's about **setting the right vibe**. You bring the intent, the AI handles the implementation. This workshop teaches you how to bridge the two.
